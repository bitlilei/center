# 认知智能中心静态网站

这是可直接部署到 GitHub Pages 的静态网站目录。

## 本地预览

直接用浏览器打开 `index.html` 即可预览；也可以用任意静态文件服务器托管本目录。

## GitHub Pages 部署

1. 新建 GitHub 仓库。
2. 将本文件夹内的全部文件上传到仓库根目录。
3. 在仓库 `Settings` -> `Pages` 中选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/root`，保存后等待 Pages 构建完成。

## 目录说明

- `index.html`：首页
- `research.html`：研究方向与技术积累
- `assets/images/embodied-ai-portfolio-01.png`、`assets/images/embodied-ai-portfolio-02.png`：具身智能 PPT 转换图片
- `projects.html`：项目成果
- `publications.html`：论文成果
- `team.html`：团队组成
- `join.html`：招生合作
- `assets/`：样式、脚本、图片与视频资源
